# Regla de Bitácora Continua de Estudio

## Objetivo
Monitorear y documentar de forma continua el proceso de aprendizaje del estudiante en la materia de Programación Funcional, registrando cada indicación, material generado, timestamp y respuesta en [`docs/bitacora_de_estudio.md`](file:///c:/Users/bh324/OneDrive/Datos%20adjuntos/Programaci%C3%B2n%20funcional/docs/bitacora_de_estudio.md).

## Instrucciones de Ejecución
1. Para cada mensaje recibido del usuario, abrir y actualizar [`docs/bitacora_de_estudio.md`](file:///c:/Users/bh324/OneDrive/Datos%20adjuntos/Programaci%C3%B2n%20funcional/docs/bitacora_de_estudio.md).
2. Insertar una nueva entrada con:
   - **ID / Nro. de Entrada**
   - **Fecha y Hora (Timestamp)**
   - **Indicación del Usuario (Prompt)**
   - **Respuesta y Material Generado**
   - **Eje Temático / Concepto Abordado**
   - **Observaciones del Proceso de Estudio (Metacognición / Patrones de Estudio)**
3. Asegurar que los enlaces a archivos o materiales complementarios dentro del repositorio se mantengan accesibles.
